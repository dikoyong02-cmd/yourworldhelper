📖 앱 사용 안내 & 매뉴얼
1. 테마 및 디자인 맞춤 설정
  • 우측 상단의 [🎨 테마 변경] 드롭다운 메뉴를 통해 6가지 테마(Classic, Dark, Emerald, Sunset, Cyber, Pastel) 중 원하는 분위기를 선택할 수 있습니다.
  • 선택한 테마는 브라우저에 저장되어 재방문 시에도 계속 유지됩니다.
2. 프로필/원하는 이미지 설정 가이드
  • 우측 사이드바의 USER PROFILE에서 로컬 이미지 파일 업로드 또는 외부 이미지 URL을 입력할 수 있습니다.
  • 맞춤 옵션:
    • Cover (채우기): 영역을 여백 없이 가득 채웁니다. (기본값)
    • Contain (맞추기): 이미지 전체 비율을 유지하며 여백에 맞춥니다.
📌 참고사항 (Recommendation)
  • 권장 이미지 해상도: 정사각형(1:1 비율) 및 300x300px 이상 크기의 이미지를 사용할 때 가장 깔끔하게 표시됩니다.
  • 권장 파일 형식: `.png`, `.jpg`, `.webp` 등의 표준 웹 이미지 포맷.
  • 자동 저장 기능: 등록한 프로필 이미지와 선택한 테마는 웹 브라우저의 `localStorage`에 자동 저장되어 페이지를 새로고침해도 유지됩니다.
⚠️ 주의사항 (Caution)
  • 대용량 이미지 파일 지양: 5MB 이상의 너무 큰 이미지 파일을 업로드할 경우 브라우저의 `localStorage` 용량 한계(보통 5~10MB)로 인해 이미지 저장이 실패하거나 작동이 느려질 수 있습니다.
  • URL 이미지 사용 시 (CORS/만료 이슈): 웹 URL 주소로 이미지를 설정할 경우 해당 외부 웹사이트의 차단 정책(CORS) 또는 링크 만료에 의해 이미지가 로드되지 않을 수 있습니다. 차단되는 링크는 직접 파일 다운로드 후 [파일 선택]으로 등록하는 것을 권장합니다.
  • 개인정보 유의: 공용 PC 사용 시 프로필 이미지나 메모장에 민감한 개인정보를 남기지 않도록 유의하세요.
